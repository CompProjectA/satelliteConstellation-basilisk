------------------------------------------------------------
BASILISK 2.2.1 INSTALLATION NOTE
------------------------------------------------------------

This text file provides important setup information that must be followed before using the guide video.

------------------------------------------------------------
REQUIRED FILES
------------------------------------------------------------

Before starting the installation steps shown in the guide video, make sure you have downloaded the following two files:

1. Basilisk Installation Guide on Windows (PDF)
   - This document contains the detailed written setup instructions for Basilisk v2.2.1.
   - Keep it open while watching the guide video to cross-check commands and configuration details.

2. Requirements Verification File (requirements 1.pdf)
   - This file lists all the Python libraries required for Basilisk and their compatible versions.
   - It must be used to confirm that your environment has the correct dependencies installed.


------------------------------------------------------------
VERIFYING BEFORE RUNNING CONAN
------------------------------------------------------------

Do not run Conan before verifying that:
- The Python version in your virtual environment is correct (3.x, not 4.x).
- All required libraries are installed and match the versions shown in the requirements PDF.

After Conan completes successfully, proceed with CMake and build steps as shown in the guide video.
